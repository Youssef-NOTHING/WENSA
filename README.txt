WENSA local demo — HTML/CSS/JavaScript
Open index.html to view the site and admin.html to manage products.
Demo password: wensa2026

Admin supports adding products, uploading a product image (image/*, max 2 MB), previewing it, modifying products, deleting products, hiding/showing products, viewing locally saved contact messages, and exporting a JSON backup.

Data and uploaded images are stored in this browser's localStorage only. This is a local prototype, not secure production authentication. Do not publish the admin page as-is or store sensitive customer data.
